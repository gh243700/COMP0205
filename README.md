# Real-time Voice Translator

A real-time voice translation system that supports English and Korean languages. The application provides instant voice-to-voice translation with a clean and user-friendly interface.

## Features

- Real-time voice input processing
- Automatic language detection (English/Korean)
- Text-to-speech output
- Clean and intuitive interface
- Easy exit commands

## Requirements

- Python 3.10+
- See `requirements.txt` for Python dependencies

## Installation

1. Clone the repository:
```bash
git clone [your-repo-url]
cd [repository-name]
```

2. Install dependencies:
```bash
pip install -r requirements.txt
```

## Usage

Run the translator:
```bash
python main1.py
```

- Speak naturally in English or Korean
- The translation will be shown and spoken
- Say "stop translation" or press Ctrl+C to exit
